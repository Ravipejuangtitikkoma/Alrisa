📖 Buku Panduan & Dokumentasi Integrasi ALRISA

Panduan resmi langkah demi langkah cara menghubungkan Aplikasi Mobile HP (Alrisa) dan Perangkat Keras (ESP32, Relay Gerbang, PLC) ke Cloud Hub, dilengkapi tabel pinout hardware dan contoh kode koneksi.

1
Unduh & Pasang Aplikasi Alrisa di HP Android

File installer aplikasi Android berekstensi .apk sudah tersedia di folder utama proyek (alrisa.apk).

  • Salin file alrisa.apk ke smartphone Android pengguna (via kabel USB, WhatsApp, atau Google Drive).
  • Buka file tersebut di smartphone dan klik Instal. Jika muncul peringatan keamanan, pilih "Izinkan penginstalan dari sumber ini" (Install from unknown source).
  • Buka aplikasi ALRISA yang sudah terpasang di layar utama smartphone.
Catatan Teknis: Aplikasi mobile ini dibangun menggunakan framework modern Flutter (Google) sehingga mendukung performa animasi tinggi dan konsumsi baterai rendah.
2
Atur Alamat IP Server Backend Cloud di HP

Agar aplikasi HP dapat menyapa Server Cloud Hub dan mengambil daftar perangkat, HP harus mengetahui alamat IP / Domain server:

  • Mode Jaringan Wi-Fi Lokal (Uji Coba di Rumah/Kantor):
    Pastikan HP dan Komputer Server tersambung ke Wi-Fi yang sama. Masukkan URL: http://192.168.1.8:3000 (sesuaikan dengan IP komputer server Anda).
  • Mode Hosting Online / VPS (Akses dari Mana Saja via Internet):
    Gunakan domain publik atau IP VPS Anda, misalnya: http://alrisa-cloud.com:3000.

Aplikasi HP akan otomatis menyimpan alamat server ini secara lokal di file alrisa_server_ip.txt sehingga pengguna tidak perlu memasukkan ulang saat membuka aplikasi kembali.

4
Sinkronisasi Otomatis Dua Arah (Cloud Sync Service)

Setelah login berhasil, sistem otomatis bekerja di latar belakang (Background Sync):

  • HP Menarik Data (GET): Aplikasi HP langsung mengambil daftar nama gerbang, pin saklar, dan streaming kamera CCTV dari server Cloud Hub.
  • Update Berkala (Polling Tiap 10 Detik): Jika Super Admin di website mengganti nama gerbang atau link RTSP CCTV, tampilan HP otomatis ter-update tanpa perlu me-refresh aplikasi.
  • HP Menyimpan Perubahan (POST): Jika pengguna menambahkan jadwal otomatisasi di HP, data langsung tersimpan kembali ke database MySQL di backend.
Koneksi Sukses: Indikator status di pojok atas layar HP akan berwarna Hijau menandakan HP tersambung 100% ke Cloud Hub dan siap mengontrol gerbang!
1
Skema Pengkabelan (Wiring Relay ke Dinamo Gerbang / Lampu)

Modul relay digunakan sebagai saklar kering (Dry Contact) yang memicu pergerakan motor dinamo pagar atau saklar lampu:

No Terminal Modul Relay Pin Mikrokontroler (ESP32) Keterangan / Fungsi
1 VCC (Power 5V) Pin 5V / VIN (Power Eksternal 5V DC) Daya modul relay (Gunakan adaptor terpisah jika relay > 4 channel)
2 GND Pin GND (Ground Bersama) Grounding bersama antara ESP32 dan modul relay
3 IN 1 (Relay Pagar Utama) GPIO 12 (Pin D12) Pemicu dinamo gerbang utama (Pulsa 1 detik memicu buka/stop/tutup)
4 IN 2 (Relay Pagar Belakang) GPIO 14 (Pin D14) Pemicu dinamo gerbang samping / belakang
5 IN 3 (Relay Lampu Teras) GPIO 27 (Pin D27) Saklar ON/OFF penerangan teras depan
6 Terminal COM & NO (Relay) Koneksi ke Saklar Manual Dinamo Hubungkan kabel COM dan NO secara paralel ke tombol push button manual motor pagar
Tipe Saklar Kering (Dry Contact): Terminal relay (COM dan NO) bertindak seperti tombol tekan biasa. Jangan alirkan tegangan 220V ke terminal dinamo kecuali dinamo tersebut memang memerlukan tegangan AC!
2
Mengunggah (Upload) Firmware ke ESP32 / ESP8266

Firmware mikrokontroler siap pakai berada di dalam folder proyek gateway/esp32_relay_pagar.ino.

  • Buka program Arduino IDE di komputer Anda.
  • Buka file gateway/esp32_relay_pagar.ino.
  • Atur nama Wi-Fi dan password di bagian atas kodingan:
    Konfigurasi Wi-Fi & Broker MQTT (gateway/esp32_relay_pagar.ino)
    // Atur nama Wi-Fi rumah dan password const char* ssid = "NAMA_WIFI_RUMAH"; const char* password = "PASSWORD_WIFI_ANDA"; // Broker MQTT resmi sistem Alrisa const char* mqtt_server = "broker.emqx.io"; const int mqtt_port = 1883; const char* mqtt_prefix = "alrisa/client"; // Sesuaikan dengan akun
  • Colokkan ESP32 ke port USB laptop menggunakan kabel data.
  • Pilih Board: ESP32 Dev Module dan Port COM yang sesuai, lalu klik tombol Upload (Tanda Panah Kanan).
3
Standar Komunikasi Topik MQTT Alat

Alat dan Cloud Hub berkomunikasi menggunakan protokol standar industri MQTT (Message Queuing Telemetry Transport):

  • Topik Perintah Kontrol (Set): [prefix]/[device_id]/set
    Contoh: alrisa/pagar/set dengan payload OPEN atau CLOSE. Alat mendengarkan topik ini. Saat menerima perintah, relay terpicu.
  • Topik Respon Status (State): [prefix]/[device_id]/state
    Contoh: alrisa/pagar/state dengan payload OPEN atau CLOSED. Alat mengirim topik ini setelah relay berhasil bekerja agar layar Web dan HP ter-update.
  • Topik Heartbeat (Detak Jantung Alat): alrisa/gateway/heartbeat
    ESP32 mengirim data JSON tiap 10 detik berisikan status online, IP lokal, dan suhu chip sehingga Web Dash Admin mengetahui alat selalu aktif (Online).
4
Mode Gateway PLC Industri (Mitsubishi FX5U)

Jika instalasi menggunakan PLC Mitsubishi FX5U (untuk gerbang pabrik atau gedung besar):

  • Hubungkan port Ethernet PLC FX5U ke switch jaringan lokal menggunakan kabel LAN RJ45.
  • Protokol yang digunakan: Modbus TCP (Port 502). Alamat IP default PLC: 192.168.1.100.
  • Mapping Register Coil PLC:
    • %QX0.0 : Output Motor Gerbang Utama Depan
    • %QX0.1 : Output Motor Gerbang Belakang
    • %QX0.2 : Output Lampu Perimeter & Teras
    • %QX0.3 - %QX0.7 : Output Tambahan Pompa / Barrier Gate
  • Jalankan skrip gateway Python di server: python gateway/minipc_plc_gateway.py.

Kode di Sisi Alat Hardware (ESP32 / C++ Arduino)

Program mikrokontroler mendengarkan perintah dari Cloud dan menggerakkan relay fisik dinamo gerbang:

C++ Arduino (gateway/esp32_relay_pagar.ino)
// Callback saat ada instruksi masuk dari Web atau HP void mqttCallback(char* topic, byte* payload, unsigned int length) { String message = ""; for (int i = 0; i < length; i++) { message += (char)payload[i]; } // Jika menerima perintah 'OPEN', aktifkan relay gerbang (GPIO 12) if (message == "OPEN") { digitalWrite(RELAY_PAGAR_PIN, LOW); // Relay Aktif (Pemicu Dinamo Buka) delay(1000); // Pulsa pemicu 1 detik digitalWrite(RELAY_PAGAR_PIN, HIGH); // Standby // Kirim konfirmasi status balik ke HP dan Web mqttClient.publish("alrisa/pagar/state", "OPEN"); } }
!
HP Menampilkan Status "Gagal Terhubung ke Server / Offline"
  • Penyebab 1: Alamat IP Server Berubah. Jika laptop/komputer server me-restart Wi-Fi, IP lokal (misal 192.168.1.8) bisa berubah. Cek IP komputer via CMD (ketik ipconfig), lalu perbarui alamat IP di HP.
  • Penyebab 2: Server Backend Node.js Belum Berjalan. Pastikan jendela terminal server backend berjalan (npm start atau node server.js) dan menampilkan tulisan "Server running on port 3000".
  • Penyebab 3: Terblokir Firewall Windows. Buka Windows Defender Firewall -> Izinkan port 3000 (TCP) masuk agar HP dapat mengakses server.
!
Tombol di HP / Web Diklik, tapi Gerbang Tidak Merespons
  • Cek Koneksi ESP32: Buka Serial Monitor di Arduino IDE pada baud rate 115200. Pastikan ESP32 sudah menampilkan status "Wi-Fi Connected" dan "MQTT Connected".
  • Cek Kabel Jumper Relay: Pastikan kabel jumper dari GPIO 12 ke pin IN modul relay terpasang kencang dan tidak goyang.
  • Cek Prefix Topik MQTT: Pastikan prefix topik di kodingan alat (alrisa/client) sama persis dengan yang diatur di menu Konfigurasi & MQTT pada website.
!
Kamera CCTV Tidak Menampilkan Gambar di Layar
  • Pastikan link streaming RTSP / HLS kamera CCTV dapat diakses dari jaringan lokal yang sama.
  • Jika menggunakan kamera IP Hikvision / Dahua, pastikan username dan password di URL RTSP sudah benar, contoh: rtsp://admin:password@192.168.1.50:554/Streaming/Channels/101.

PENJELASAN LINK WEBSITE VS APLIKASI HP
❓ Mengapa RTSP tidak muncul langsung di browser web?
Browser web (Chrome, Edge, Firefox) secara standar tidak mendukung protokol RTSP secara langsung. Di Aplikasi HP (Flutter), RTSP berjalan lancar karena HP memiliki pemutar VLC bawaan.

Cara agar kamera HP Anda menyala live di Website ini:

  1. Pastikan HP dan Laptop/PC terhubung ke jaringan Wi-Fi yang sama.
  2. Buka aplikasi kamera di HP (contoh paling stabil & gratis: "IP Webcam" di Play Store).
  3. Gulir ke paling bawah, lalu klik tombol "Start server".
  4. Lihat tulisan alamat IP di layar HP Anda, misalnya: http://192.168.1.15:8080.
  5. Di website Alrisa, masukkan URL dengan menambahkan /video di belakangnya:
    http://192.168.1.15:8080/video
  6. Klik Simpan — video kamera HP Anda langsung menyala live di website!
