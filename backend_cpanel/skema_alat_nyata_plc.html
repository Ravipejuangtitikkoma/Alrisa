SISTEM KONTROL GERBANG OTOMATIS BERBASIS PLC & CCTV LAN

Skema Alat Nyata, Jalur Kabel & Mekanik Gerbang

Diagram fisik perkabelan industri tanpa WiFi (Menggunakan Kabel LAN Ethernet RJ45 & Protokol Modbus TCP / RTSP Stream)

TAHAP 1
Smartphone / Tablet
Aplikasi Nexora
User melihat live feed kamera CCTV melalui protokol RTSP dan menekan tombol Buka Gerbang via Modbus TCP / IP.
Koneksi: Wi-Fi Router / LAN Hub
CCTV
Outdoor IP Camera
Protokol RTSP (Port 554)
Kamera pengawas dipasang mengarah ke gerbang. Mengirimkan video langsung 1080P FHD ke aplikasi Nexora tanpa jeda.
Kabel: LAN UTP RJ45 (PoE 48V / 12V)
TAHAP 2 & 3
PLC Industri (DIN-Rail)
Siemens / Outseal / Modicon
Menerima perintah via kabel LAN (Modbus TCP). Menjalankan logika keamanan, lalu mengaktifkan Relay Output %QX0.0 (Q1).
Input: 24V DC | Output: Relay Dry Contact
TAHAP 4
Mesin Motor Pagar
Sliding Gate Motor (AC/DC)
Menerima sinyal kontak dari PLC. Memutar dinamo berkekuatan besar untuk memutar Pinion Gear (Roda Gigi).
Daya: 220V AC / 24V DC (Torsi 50-80 Nm)
TAHAP 5
Mekanik Pagar Besi
Steel Gear Rack & Track
Rel gigi baja bergerak mengikuti putaran motor. Pagar meluncur buka/tutup dan berhenti pas di sensor Limit Switch.
Sensor: 24V Photocell Beam Anti-Jepit
